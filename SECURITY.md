# Security Policy

## Supported versions

Security fixes are provided for the latest published version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`yoshi@musicailab.com` with the affected version, impact, reproduction steps,
and any suggested mitigation.

You can expect an acknowledgement within 72 hours and an initial assessment
within seven days.

## Security scope

Reports involving project-memory disclosure, unsafe path handling, malformed
MCP requests, database corruption, or dependency compromise are especially
valuable. Never include real private keys, wallet seed phrases, or production
credentials in a report.
